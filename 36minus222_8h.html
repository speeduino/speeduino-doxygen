Detailed Description

36-2-2-2 crank based trigger wheel.

A crank based trigger with a nominal 36 teeth, but 6 of these removed in 3 groups of 2. 2 of these groups are located concurrently.

Note
: This decoder supports both the H4 version (13-missing-16-missing-1-missing) and the H6 version of 36-2-2-2 (19-missing-10-missing-1-missing) The decoder checks which pattern is selected in order to determine the tooth number
