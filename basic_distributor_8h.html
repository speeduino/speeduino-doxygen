Detailed Description

Basic Distributor where tooth count is equal to the number of cylinders and teeth are evenly spaced on the cam.

No position sensing (Distributor is retained) so crank angle is a made up figure based purely on the first teeth to be seen.

Note
This is a very simple decoder. See http://www.megamanual.com/ms2/GM_7pinHEI.htm
