◆ INTERNAL_TEST_ASSERT

#define INTERNAL_TEST_ASSERT (   expression)

A unit test only assert.

Useful for asserting non-unit test code during unit tests. A regular assert will exit(1) on AVR, which is not useful

◆ TESTABLE_CONSTEXPR
