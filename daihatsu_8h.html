Detailed Description

Daihatsu +1 trigger for 3 and 4 cylinder engines.

Tooth equal to the number of cylinders are evenly spaced on the cam. No position sensing (Distributor is retained), so crank angle is a made up figure based purely on the first teeth to be seen.

Note
: This is a very simple decoder.
